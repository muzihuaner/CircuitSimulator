# 快点电路模拟器

一个基于 Falstad 电路模拟器的网页应用程序，提供交互式电路设计和仿真功能。

## 项目描述

这是一个电子电路模拟器网页应用，内嵌 Falstad Circuit Simulator，允许用户可视化和模拟电路工作原理。默认加载一个简单的 LRC 电路示意图。

## 功能特性

- 📌 **集成 Falstad 电路模拟器** - 功能强大的在线电路仿真工具
- 🔌 **电路可视化** - 实时显示电压、电流和电路状态
- 🎨 **颜色编码** - 不同颜色表示不同的电气状态
- ⚙️ **交互式编辑** - 支持修改电路元件参数
- 📚 **内置帮助** - 用户友好的说明和文档链接
- 📱 **响应式设计** - 适配各种屏幕尺寸

## 电路颜色说明

| 颜色 | 含义 |
|------|------|
| 🟢 绿色 | 正电压 |
| ⚪ 灰色 | 接地 |
| 🔴 红色 | 负电压 |
| 🟡 黄色圆点 | 电流流向 |

## 快速开始

### 使用方法

1. 打开 `index.html` 文件即可在浏览器中运行程序
2. 点击右下角的 **?** 按钮查看使用说明
3. 点击电路中的开关来打开或关闭它
4. 将鼠标悬停在元件上查看其状态和说明
5. 右键单击（Mac 用户按 Ctrl+点击）元件可编辑其参数

### 系统要求

- 现代网络浏览器（支持 HTML5）
- 互联网连接（用于加载 Falstad 模拟器）

## 主要功能模块

### 帮助弹窗
- 右下角圆形帮助按钮，点击显示详细的使用说明
- 支持点击关闭按钮或外部区域关闭弹窗

### 电路模拟
- 嵌入式 iframe 加载 Falstad 电路模拟器
- 默认加载 LRC 电路示例
- 提供丰富的示例电路库供选择

## 进阶功能

- 通过"电路"菜单访问多个示例电路
- 完整的电路元件库（电阻、电容、电感、电源等）
- 支持自定义电路设计
